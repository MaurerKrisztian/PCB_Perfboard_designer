Open the designer

MCP server · Free · No sign-up

Design perfboards with your AI assistant

Connect Claude, ChatGPT, Cursor or any other MCP client to Perfboard Designer and describe the circuit you want. The assistant looks up the parts, places them on a perfboard or stripboard, routes the wires, checks every connection, and gives you a link that opens the finished board in the designer.

Server address
https://mcp.perfboarddesigner.com/mcp

Streamable HTTP · no account or API key needed

What you can ask

Once it's connected, just ask in your own words.

"Lay out a 555 LED blinker on a small perfboard and send me the link."
"Put this circuit on a 30 × 20 stripboard and cut the strips under the chip."
"Here's my board link. Add a power LED with a resistor and check nothing is left unconnected."

Set it up

Pick your assistant. Every one uses the same address.

Claude Code

Run this in a terminal:

claude mcp add --transport http perfboard https://mcp.perfboarddesigner.com/mcp

Add --scope user to have it in every project, not just the current folder. Check it with /mcp inside Claude Code.

Claude.ai & Claude Desktop

  1. Open Connectors in Claude's settings and choose Add custom connector.
  2. Name it Perfboard Designer and paste the address:
    https://mcp.perfboarddesigner.com/mcp
  3. Click Add. There's no sign-in, so leave the advanced (OAuth) settings empty.
  4. In a chat, open the + menu, then Connectors, and turn Perfboard Designer on.

A connector added once works on claude.ai, in Claude Desktop and in the mobile apps. On Team and Enterprise plans an owner adds it for the organization first. Custom connectors depend on your Claude plan.

ChatGPT

  1. In Settings → Apps & Connectors → Advanced settings, turn on Developer mode.
  2. Back in Apps & Connectors, choose Create, name it Perfboard Designer and paste the address:
    https://mcp.perfboarddesigner.com/mcp
  3. Set authentication to No authentication and create it.
  4. In a chat, pick it from the + menu under Developer mode.

Developer mode is on paid ChatGPT plans, and OpenAI moves these menus from time to time.

Cursor

Add it to ~/.cursor/mcp.json (every project) or .cursor/mcp.json (one project):

{
  "mcpServers": {
    "perfboard": {
      "url": "https://mcp.perfboarddesigner.com/mcp"
    }
  }
}

VS Code (GitHub Copilot)

Add it to .vscode/mcp.json in your project, or run MCP: Add Server from the Command Palette:

{
  "servers": {
    "perfboard": {
      "type": "http",
      "url": "https://mcp.perfboarddesigner.com/mcp"
    }
  }
}

Then use it from Copilot Chat in agent mode.

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "perfboard": {
      "serverUrl": "https://mcp.perfboarddesigner.com/mcp"
    }
  }
}

Gemini CLI

gemini mcp add --transport http perfboard https://mcp.perfboarddesigner.com/mcp

Or add it to ~/.gemini/settings.json by hand. Note the key is httpUrl, not url:

{
  "mcpServers": {
    "perfboard": {
      "httpUrl": "https://mcp.perfboarddesigner.com/mcp"
    }
  }
}

Codex CLI

codex mcp add perfboard --url https://mcp.perfboarddesigner.com/mcp

Or add it to ~/.codex/config.toml:

[mcp_servers.perfboard]
url = "https://mcp.perfboarddesigner.com/mcp"

Other clients

Any client that supports remote MCP servers over Streamable HTTP works: give it the address https://mcp.perfboarddesigner.com/mcp, with no authentication.

For a client that can only start local (stdio) servers, bridge to it with mcp-remote, which needs Node.js:

{
  "mcpServers": {
    "perfboard": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://mcp.perfboarddesigner.com/mcp"]
    }
  }
}

Run it yourself

The server is open source, so you can also run it on your own computer over stdio, with nothing sent anywhere. You need Node.js 22 or newer:

git clone https://github.com/MaurerKrisztian/perfboard-designer.git
cd perfboard-designer/mcp
npm install
npm run build

Then add it to your client as a command. In Claude Code:

claude mcp add perfboard -- node /path/to/perfboard-designer/mcp/dist/server.js

Other clients take the same command and argument ("command": "node", "args": ["/path/to/…/dist/server.js"]). The server's README also covers hosting your own copy on Cloudflare Workers.

What it does

The assistant works with the same parts, rules and checks as the designer, so what it builds opens exactly as it planned.

🔎

Looks up parts

Every part in the designer's library, with its pins, pin labels and polarity: resistors, capacitors, LEDs, transistors, chips, dev boards and more.

🧩

Builds the board

Starts a perfboard or stripboard of any size, places parts, routes wires pin to pin and cuts strips, in small edits that each go in whole or not at all.

✅

Checks the wiring

Lists the board's nets and catches pins left unconnected, parts sharing a hole, shorted supply rails and strips that short a chip's pins. Given the netlist you meant, it reports every missing or extra connection.

🔗

Hands you a link

The finished board comes back as a share link, with a picture of it, and a short link too if you ask. Click it and the board opens in the designer as a new project, ready to change, save or view in 3D.

✏️

Edits your boards

Share a board link with the assistant and it can read the board, change it and give you a new link.

🗺️

Shows its work

It can draw the board as text and list where every pin lands, so it sees free space and plans the routing before it places anything.

Good to know

Does it cost anything or need an account?

No. The hosted server is free and has no sign-in. You only need an AI assistant that supports MCP.

What happens to my boards?

While the assistant works on a board, the server keeps a copy under a random project id, deleted after 30 days unused. The board you get back travels inside the share link itself, and opening it saves it in your own browser, like any other project.

If you ask for a short link, the board is also stored at projects.perfboarddesigner.com under a readable id, such as led-blinker. Anyone with that link can open it. A stored board never changes (after an edit, the assistant stores a new one) and is deleted after a year unopened. The full link always comes too, and works without the server.

Does it simulate my circuit?

No. It checks how the board is wired (which pins are connected), not how the circuit behaves. Check the design itself before you build it.

My assistant doesn't use it.

Make sure the server is turned on for the chat (in claude.ai and ChatGPT, from the + menu), then mention it: "use Perfboard Designer to lay this out".

Where's the source code?

In the mcp folder on GitHub, next to the designer it's built on. Bug reports and ideas are welcome.
